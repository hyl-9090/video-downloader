高级（一般用不到）：需要登录才能看的内容

「cookie」是什么？可以理解成你登录网站后的一张临时通行证，网站靠它认出你是会员。 不知道是什么就完全不用管，留空即可 —— 绝大多数视频都不需要它。

什么情况才需要填：

  • B站想下 1080P 以上 / 大会员专属 画质
  • 抖音、小红书、视频号提示「需要登录」才能看
  • 想下自己账号里的私密 / 仅粉丝可见内容
怎么拿到？两种方法，任选一种

方法一 · 不用装任何东西（推荐，1 分钟搞定）

  1. 用电脑浏览器打开那个视频网站，并登录自己的账号
  2. 按键盘 F12，打开「开发者工具」，切到 网络 / Network 那一栏
  3. 按 F5 刷新一下页面，在左边随便点一条出现的请求
  4. 右边找到 请求标头 / Request Headers，里面有一行以 Cookie: 开头
  5. 把 Cookie 后面那一整串（长得像 SESSDATA=xxx; bili_jct=yyy; …）复制下来， 粘到下面的框里 —— 不用管格式，程序会自动转换

方法二 · 装个浏览器扩展（以后省事）

  1. 给浏览器装「Get cookies.txt LOCALLY」这个扩展（Chrome / Edge 商店里搜得到）
  2. 登录要下载的那个网站，点扩展图标 → Export / 导出
  3. 用记事本打开导出的 cookies.txt，全选复制，粘到下面的框里

⚠️ 扩展名必须带 LOCALLY，同名的旧版本扩展有过安全问题，别装错。

🔐 安全提醒：这一段内容等于你的登录凭证，拿到它的人可以冒充你登录。 千万不要发给别人（包括发到群里）。本程序只在你这台电脑上用一次，下载完立刻删除，不会上传到任何地方。

📖 使用说明
1
复制视频链接
打开要下载的视频，点「分享」→「复制链接」。各平台具体位置见下面第二条。
2
粘到最上面的输入框，点「解析」
抖音、小红书等 App 复制出来的是一整段带汉字的文案，直接整段粘进去就行，程序会自动把链接挑出来。
3
在列表里选清晰度，点「⬇ 开始下载」
列表里每一行就是一个清晰度（1080P / 720P…），后面标了预计文件大小。下完点「▶ 打开/下载」就能看。
🎬 各平台怎么复制链接
平台能不能下怎么复制链接 / 说明
B站✅ 能 播放页点「分享」→「复制链接」。也可以只粘 BV 号（如 BV1GJ411x7h7）。 番剧、直播回放、合集也能下。多P视频下的是你复制的这一 P。
抖音✅ 能 点「分享」→「复制链接」。复制到的是一整段文案，直接整段粘就会自动识别。下的是无水印版。
小红书✅ 能 笔记右上「分享」→「复制链接」。部分笔记需要登录凭证（见最上面「高级」）。
微博✅ 能 微博正文或视频页点「分享」→「复制链接」。支持 weibo.com/数字/…、 weibo.com/tv/show/…、m.weibo.cn/status/… 几种形式。
腾讯视频 / 优酷 / 爱奇艺 / 芒果TV✅ 能 直接复制浏览器地址栏。会员内容需要登录凭证；有版权保护的剧集可能下不了。
西瓜视频 / AcFun / 搜狐视频✅ 能 直接复制浏览器地址栏。
斗鱼 / 虎牙✅ 能 直播回放、视频页地址直接复制。
喜马拉雅 / 网易云音乐 / QQ音乐 / 酷我🟡 看情况 音频类，程序是认的，但音乐平台大多需要登录或会员才能拿到完整文件，部分只给试听片段。 另外「酷我」要用 kuwo.cn/yinyue/数字 这种形式的链接， 现在网页上复制的 /play_detail/ 形式认不出。以实测结果为准。
YouTube🟡 看情况 直接复制浏览器地址栏。需要这台电脑能正常打开该网站；而且 YouTube 近年加强了限制， 部分视频可能解析不到（会提示「没找到可下载的视频」），那就换一个来源试试。
微信视频号❌ 不行 微信的视频是加密的、必须登录微信才能看，公开的下载工具都拿不到。 替代办法：请作者把原视频发给你，或者用手机「屏幕录制」录下来。
快手❌ 不行 下载引擎（yt-dlp）还没有支持快手。可以看作者是否允许「保存到相册」，或用手机录屏。
微视 / 咪咕视频 / 皮皮虾❌ 不行 下载引擎还没有支持这几个平台。
其它网站✅ 多数能 支持 1700 多个网站。直接复制浏览器地址栏试一下，解析不了就是不行。
上面「能不能下」是实际测过的结果，不是估计的。遇到不支持的平台，页面会直接告诉你原因和替代办法，不会只丢一串英文报错。
❓ 常见问题（点开看）

Q：点了「解析」没反应 / 提示解析失败？
A：① 重新复制一次链接，确认复制完整；② 确认这台电脑能正常打开那个网站；③ 换一个视频试试—— 有些内容网站本身就不允许下载（付费、有版权限制等）。

Q：列表里的「需合并」是什么意思？
A：清晰度越高，网站在服务器上是把「画面」和「声音」分开存的。程序下载后会自动拼成一个完整视频， 多等十几秒是正常的，不是卡住了。

Q：第一次打开特别慢 / 一直显示「正在准备」？
A：第一次运行要下载一个约 50MB 的合并组件（页面顶部有进度提示）。只下载这一次，以后打开就快了。

Q：下载好的文件在哪里？
A：双击运行的这个版本，文件存在「下载」文件夹里名为 视频下载器 的文件夹中； 下载完成后，页面上「▶ 打开/下载」也可以直接点开。

Q：为什么最高只有 480P / 360P？
A：网站没有给更高码率就是没有（未登录时 B站 常常只给到 480P）。 想拿更高画质，需要登录凭证，见最上面「高级」那一栏。

Q：我按方法一填了 cookie，可还是只有 480P？
A：按顺序检查：① 你登录的那个账号本身是不是大会员（普通账号登录也拿不到大会员画质）； ② cookie 可能过期了——重新按方法一复制一次；③ 复制时确认完整复制到最后，别只复制一半。

Q：填了 cookie 之后，画质反而变低了？
A：说明这串 cookie 无效或已经过期——网站认不出你是会员，就按「未登录」处理了。 把框清空再解析一次通常就恢复；要填就填刚复制下来、最新的那一串。

Q：填了 cookie 会不会有风险？
A：cookie 相当于你的登录凭证，所以千万别发给别人。就本程序而言：它只在你自己的电脑上运行， 这段内容只在下载时临时用一下、用完立刻删除，不会上传、也不会保存下来。

Q：能一次下载整个合集 / 播放列表吗？
A：目前一次下载一个视频。多P视频下载的是你复制链接时的那一个 P。

Q：下载会记录我看了什么吗？
A：不会。这是在本机运行的小程序，只做「下载」这一件事， cookie（如果填了）也只用于当前这一次下载，用完即删，不会上传到任何地方。
