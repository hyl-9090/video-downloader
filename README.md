# 视频下载器

一个**给老师用**的视频下载小工具：把视频链接粘进来 → 选清晰度 → 下载。
双击即用，不需要安装任何东西，不需要懂命令行。

底层基于 [yt-dlp](https://github.com/yt-dlp/yt-dlp)，支持 **1700 多个网站**。

## 特点

- **双击即用** — 自动起本地服务并打开浏览器，用完关掉窗口即可
- **界面极简** — 没有一屏看不懂的格式表，只有「清晰度 + 文件大小」几行
- **分享文案直接粘** — 抖音等 App 复制出来的一整段带汉字的文案，会自动把链接挑出来
- **自动合并音视频** — 高清画质在服务器上是画面、声音分开存的，程序会自动拼好
  - Windows：用 ffmpeg（首次运行自动下载一次，之后复用）
  - HarmonyOS：用内置的 Python 合并器，完全不需要 ffmpeg
- **面向非技术用户** — 全中文说明、报错说人话、页面自带《使用说明》和常见问题
- **跨平台** — 在 HarmonyOS 7 (aarch64) 与 Windows 上均验证通过

## 怎么用

1. 打开视频页，点「分享」→「复制链接」
2. 粘进输入框，点「解析」
3. 选清晰度，点「⬇ 开始下载」

需要登录才能看的内容（例如 B站 1080P 以上 / 大会员专属），可在页面「高级」里填入 cookie，
两种格式都认：浏览器 `F12` 里复制的 `SESSDATA=…; bili_jct=…`，或扩展导出的 `cookies.txt`。

> ⚠️ cookie 等同于你的登录凭证，**不要分享给他人**。程序只在本机使用、用完即删、不上传。

## 打包 Windows exe

```bash
pip install pyinstaller yt-dlp
python build_win.py
```

产物在 `dist/视频下载器.exe`（约 17.6 MB）。

**注意**：Windows on ARM 上必须使用 **x86-64（amd64）版 Python**。
ARM64 原生版会因 PyInstaller 缺少 arm64 引导器而打包失败。

## 已知限制

- **微信视频号、快手、微视、咪咕视频、皮皮虾**：引擎层面没有对应提取器，无法下载
- 一次只下载一个视频；多P视频下载的是所复制链接的那一个 P
- 音乐平台（网易云 / QQ音乐 / 酷我）大多需要登录或会员才能拿到完整文件
  - 酷我只认 `kuwo.cn/yinyue/<数字>` 形式的链接
- 合并阶段没有细分进度条
